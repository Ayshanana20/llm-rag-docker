# Local RAG Assistant with Dynamic PDF Upload

A local Retrieval-Augmented Generation (RAG) application built with Python, Streamlit, FastAPI, and `pypdf`.

## Features
- Dynamic PDF and text file upload via Streamlit web interface.
- Text extraction and parsing using `pypdf`.
- Local search and query retrieval.
